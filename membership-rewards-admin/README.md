# 会员与邀请奖励配置

领榜运营中心的独立后台原型，使用 Vue 3、TypeScript、Vite 和现有 Element Plus 2.14.5。交付文件为上一级 `会员与邀请奖励配置.html`，脚本、样式和图标全部内联，可离线打开。配置及演示记录仅保存在当前浏览器。

## 当前页面

| 页面 | 配置与操作 |
| --- | --- |
| 会员配置 | 会员设置、标识图标、最多5项权益；购买方案新增、编辑和上下架 |
| 优惠券配置 | 金额券／抵用券模板新增、编辑和复制；有效期、发放上限及逐券用券规则 |
| 需求支付 | 发布需求的支付开关、单次金额、保存和取消修改 |
| 活动管理 | 查询、分页、新增、详情、编辑、复制、启停及删除无记录活动；配置参与条件和会员／优惠券奖励 |
| 运营记录 | 用户资产、邀请明细、奖励发放；筛选、详情、导出、异常核验、原单重试和撤回优惠券 |

顶部验收工具提供演示角色、模拟加载失败／恢复及重置本地演示数据。只读角色可查看、导出；无访问权限角色隐藏配置和记录。会员、优惠券和活动列表支持搜索显隐、刷新及工作区全屏。

## 当前规则

- 各配置项独立保存并立即生效；取消或关闭抽屉不提交编辑。
- 会员开关可仅停购买，或关闭会员及全部权益；全量关闭时可继续计时、暂停计时或立即失效。立即失效的旧会员不恢复，重新开启后的新购买、新赠送可生效。会员权益总数最多5项，停用项也占名额；图标仅本地读取，支持PNG／JPG／WebP、单张不超过500 KB。
- 方案价格为0.01～99999元、最多两位小数；开启会员购买时至少有一个上架方案。初始月会员19.9元、年会员99.9元。
- 优惠券创建后锁定类型。金额券逐模板配置面额、需求单支付／会员支付／订单支付范围、无门槛／满额可用、每单张数、其他优惠同享及退款方式。门槛按其他优惠前金额判断，同模板多张累计门槛，实际抵扣不超过优惠后应付。
- 抵用券不设面额和金额门槛，抵用项目可选需求发布、接单支付；每张在所选项目中任选一次全额抵扣，每次一张，零元不消耗。有效期、发放上限、优惠同享和退款方式仍逐券配置。
- 需求支付默认开启、9.90元，普通发布和指定老师发布共用；有效会员免费，关闭收费后所有人免费。金额范围0.01～99999元、最多两位小数；关闭时保留金额并禁用输入。
- 活动参与身份为家长、老师，完成条件为新用户首次有效注册。会员和优惠券可同时赠送，分别设置人数门槛、时长／模板及张数、重复奖励和个人上限。初始活动为每10人赠1个月会员、每1人赠1张2元券。
- 新用户按实际用户去重，同事件重放不重复计奖；绑定不得晚于注册。进度按用户、活动和奖励类型隔离，旧轮次保留原规则，下一轮使用新配置；各奖励失败互不回滚，重试沿用原单快照。
- 启用赠券活动需关联启用模板，停用被引用模板前须先换绑或停用活动。无参与记录、奖励或未完成进度的停用活动可删除；有记录的活动保留追溯。已使用或锁定中的优惠券不可撤回，撤回须填写原因。

## 数据保留与边界

当前存储键为 `lingbang-member-rewards-admin-v3`，兼容读取v2／v1；旧存储不删除，不自动启用旧草稿或定时计划。已发资产、旧轮次、邀请快照和日志保留；历史跨活动奖励策略继续兼容，页面不提供修改入口。

所有写操作在副本中计算，成功写入完整快照后才更新页面；存储失败保留原数据，旧标签页提交冲突要求刷新。读取失败或格式不兼容时仅展示演示数据并暂停保存，恢复读取或明确重置后再提交。

后台尚未与需求单、个人中心及真实支付／核销／退款／邀请服务联动；新增权益也不会自动生成服务能力。本机角色和存储令牌不代替生产权限与数据库事务。具体接入缺口见[逻辑检查说明](logic-closure-audit.md)。

## 开发、测试说明与需求清单

顶栏“原型说明”和“需求列表”为说明入口，默认收起。展开后右侧独立占位，业务抽屉和确认弹窗让出空间；关闭说明保留当前编辑副本。说明跟随五个菜单、记录页签、新增／编辑／查看、券类型与有效期／退款选择、业务确认、权限和异常状态。详情只显示对应查看动作，字段标为只读。

“当前页面”按操作、字段、规则、测试分类阅读；“需求列表”支持关键词、模块、实现范围筛选与分页，点击进入需求详情，查看验收标准和关联用例，返回保留查询；“完整说明”可选择全部章节。底部可下载各独立文件，离线HTML中同样可用。

当前共34个章节、40个界面场景、96项编号需求、103项字段说明、63项动作及96个测试用例基线。每个输入字段记录控件、必填、默认值、范围、联动和实际错误；动作记录权限、去向、取消和反馈；用例包含关联需求、前置、步骤和预期。用例基线不代表96项均已实测；界面已实现、模型已实现、服务待接入、业务待确认分别标记。

## 运行与验证

```sh
npm run dev
npm run docs
npm run docs:check
npm test
npm run build
```

`dev` 默认监听本机5208端口。`docs`生成四份说明文件，`docs:check`检查文档是否与规范一致；`build`先生成并校验规范，再执行类型与未使用代码检查，生成 `dist` 后重建上一级离线HTML。使用项目现有依赖，不修改相邻项目的依赖目录。

107项自动测试与构建通过，其中103项为既有业务及持久化测试、4项为规范引用与同源文档检查。浏览器复核五个菜单、记录三页签与详情、方案新增／只读、优惠券新增／编辑／复制及类型／有效期／退款说明、活动详情转编辑／新增／停用／取消奖励确认、需求列表搜索／筛选／分页／详情返回、文档下载、只读／无访问权限、加载失败恢复。隔离来源补验异常核验、关闭需求收费及活动／自定义权益删除确认；1280与1440下说明和业务浮层无重叠或页面横向溢出，收起说明保留编辑。5208未执行测试保存，已有数据保留。

主要组件：ElMenu／ElBreadcrumb用于导航，ElTable／ElPagination用于列表，ElDrawer／ElDescriptions用于编辑及详情，ElForm与输入、选择、开关、日期控件用于配置，ElMessageBox／ElAlert用于确认和异常反馈。
